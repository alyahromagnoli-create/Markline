# Markline 1.0.1 便携版使用说明

双击 Markline.exe。无需安装Python，无需联网。请把程序保存在任意盘符的可写目录。

## 我的成绩

点击“导入成绩表”，选择XLS、XLSX或CSV。核对预览后确认导入。支持表头不在首行、学期向下延续和等级成绩。支持手动添加、编辑、删除及CSV导出。

等级换算：优95，良85，中等75，合格和及格65。四六级、形势与政策和零学分课程保留记录但不计入GPA或加权平均分。异常成绩列为待处理，不擅自猜测。多工作表可在预览中选择本次导入的工作表。相同学期/课程名称/课程代码识别为同一条记录，相同跳过、变化更新；不能据此自动处理学校重修替代规则。

## 快速对比

输入双方当前计入GPA的总学分及累计平均GPA，或者切换为加权绩点总量。本人可以点击“使用我的成绩”带入精确汇总。双方数据应对应相同截止时点。不同课程集合按各自学分计算，不代表同课程水平或官方排名。

添加后续课程，双击表格编辑成绩或学分；取消“修读”表示该方不修此课。单科反推：选中目标行，点击“反推选中课程最低成绩”，其他课程保持表中假设不变。多科试算：修改目标成绩后自动重算，也可以点击“计算多科结果”。

严格大于才算反超；并列不算。90–100分均为4.0，继续提分不会增加GPA。手填GPA若已舍入，临界结果仅基于该输入值。保存对象只保存对方当前汇总；保存方案则保存双方数据和未来课程的快照。打开方案后调整，点击“保存为新方案”即可保留另一个版本。

## 数据保存

程序首次运行在EXE旁创建data文件夹；包含数据库、上次试算、运行日志及必要的本地临时目录。移动程序时请同时移动data。程序使用Windows系统临时目录解包，退出后由运行时清理。不需要D盘、Python或Excel；不要把程序放在不可写的只读位置。

数据设置中可备份和恢复。恢复前会自动备份当前数据。同一数据目录不允许同时写入。不要在程序运行时手动覆盖数据库。第三方许可内置在EXE中，可从数据设置打开。

本工具不支持60以下成绩、不自动套用学校重修政策。官方汇总与本工具重算可能存在舍入/截断或统计范围差异，原表汇总保留为参考。


## 当前便携版

本版本不要求 D 盘。程序运行库包含在单个 EXE 内，使用系统临时目录解包，数据保存到 EXE 旁的 data。只读目录请先移动到可写位置。原有个人记录需要一并复制 data，发布包不含个人数据。
